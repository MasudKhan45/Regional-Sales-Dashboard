

# Regional Sales Performance Dashboard

A Power BI dashboard built for KS AI & Cloud Solutions Data Analyst Assignment.

## Dashboard Pages
- Executive Overview — YoY Sales & Profit
- Manager Performance — Regional Manager Scorecard
- Category Targets — Achievement by Category
- Returns Analysis — Return Rate Trends
- Delivery Delays — Shipping Performance
- Action Summary — Key Business Insights

## Tools Used
- Power BI Desktop
- DAX Measures
- Data: 10,000 orders across 2015-2018
